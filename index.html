Come ottenere il Client ID gratuito:
1. Vai su console.cloud.google.com
2. Crea un progetto → "API e servizi" → "Credenziali"
3. "Crea credenziali" → "ID client OAuth 2.0" → tipo: Applicazione web
4. In "Origini JavaScript autorizzate" aggiungi http://localhost o il tuo dominio
5. Copia il Client ID e incollalo sopra
Attiva anche: Google Search Console API dalla libreria API.
